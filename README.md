## CS 250 – Software Development Lifecycle

CS 210 Project Reflection – Corner Grocer
Project Summary
The Corner Grocer project was a C++ program designed to help a grocery store track how often items were purchased. The program reads information from an input file and allows users to search for items, view purchase frequencies, and display a histogram of purchases.
What I Did Well
I did well with organizing the program into separate functions and making the menu easy to use. I also worked on making sure the program could read the input file and display the correct information.
Possible Improvements
I could improve the program by adding stronger input validation and better error handling if the input file cannot be opened. These improvements would make the program more reliable and easier to use.
Challenges and Solutions
One of the more challenging parts was working with file input and making sure the program counted items correctly. I worked through the code, tested the different menu options, and corrected problems as they came up.
Transferable Skills
This project helped me practice C++ programming, file handling, loops, functions, and working with maps to store information. These skills will be useful in future programming projects.
Maintainability and Readability
I used separate functions to organize the program and make the code easier to understand. Keeping the code organized makes it easier to find errors, update features, and maintain the program in the future.
